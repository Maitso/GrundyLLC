# GrundyLLC - Grocery App

GrundyLLC is a grocery shopping app built using ASP.NET Core MVC that integrates with Paystack for payment processing. This app allows users to browse products, add them to a cart, and choose a subscription plan (weekly or monthly). It also integrates a payment gateway for checking out orders.

## Features
- Product catalog with the ability to add items to a shopping cart
- Choose between a weekly or monthly subscription plan
- Integration with Paystack for payment processing
- Platform fee calculation and grand total calculation
- Callback for payment confirmation after successful transactions

## Prerequisites

Before you begin, make sure you have the following installed:
- [.NET 6.0 or 7.0 SDK](https://dotnet.microsoft.com/download/dotnet)
- [Visual Studio Code](https://code.visualstudio.com/) or [Visual Studio](https://visualstudio.microsoft.com/)
- [Git](https://git-scm.com/)
- [Railway Account](https://railway.app/) for deployment
- [Paystack Account](https://paystack.com/) for payment gateway integration
